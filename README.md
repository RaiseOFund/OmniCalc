OmniCalc

An advanced scientific calculator and universal conversion platform.

OmniCalc is a cross-platform calculator project designed to provide powerful mathematical calculations, scientific tools, engineering utilities, and unit conversions through a modern web application and Android app.

Features

Scientific Calculator

- Basic arithmetic operations
- Trigonometric and inverse trigonometric functions
- Logarithms and exponential functions
- Fractions, powers, roots, and factorials
- Complex numbers
- Scientific notation
- Degrees and radians modes
- Expression parsing and evaluation

Advanced Mathematics

- Algebra and equation solving
- Calculus: differentiation and integration
- Matrices and determinants
- Vectors and linear algebra
- Statistics and probability
- Numerical methods
- Graph plotting
- Symbolic mathematics

Converters

- Length, area, volume, and mass
- Temperature, speed, and acceleration
- Time, frequency, and angle
- Energy, power, and pressure
- Force, torque, and density
- Data storage and transfer rates
- Number systems and bases

Additional Tools

- Programmer calculator
- Financial and percentage calculations
- Date and time calculations
- Scientific constants and formulas
- Calculation history
- Customizable settings
- Light and dark themes
- Responsive interface
- Offline-capable functionality where supported

Platforms

- Web: Browser-based application
- Android: Android application

Technology Stack

The final technology stack will be selected to support code reuse, reliability, performance, and maintainability across platforms.

Planned components include:

- A shared calculation engine
- A reusable conversion and units library
- A modern web interface
- An Android application
- Automated tests and continuous integration
